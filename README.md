# Lights Out on MiniChain

Playable in the browser. Daily scores can be submitted to Fathom's MiniChain #1 on Robinhood mainnet. Scores are honor-system. A testnet toggle is included; mainnet is the default.

**Play:** https://dubie-eth.github.io/lights-out-minichain/

**Mint & launch:** https://dubie-eth.github.io/lights-out-minichain/chains/
